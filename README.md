Smart National Cybersecurity Awareness Metric Project:

The Smart National Cybersecurity Awareness Metric Project is an innovative initiative designed to enhance the awareness of users about the risks of cybersecurity. The project leverages artificial intelligence to dynamically assess and improve individual and institutional understanding of digital threats. Below is a detailed explanation of the project:

Why is Awareness Important?
In an increasingly digital world, cybersecurity has become a top priority to safeguard individuals and organizations from the growing risks of cyber threats. This project addresses the need for proactive measures by introducing a national cybersecurity awareness metric that evaluates users' awareness levels and strengthens society's resilience to cyberattacks.

Statistics Highlighting the Need:

84% of online fraud victims are elderly individuals.
Financial losses from internet fraud in the Arab world amount to $270 million annually.
Studies show that 85% of cyberattacks stem from human error, emphasizing the importance of raising awareness.
Proposed Solution:
The project proposes an advanced tool that uses artificial intelligence to analyze users' data and provide a dynamic evaluation of their awareness levels regarding cybersecurity threats. The evaluation takes into account multiple factors, including:

User activity on government platforms.
Educational level and professional background.
Previous cybersecurity test results.
Digital behavior patterns.
Number of government services the user is registered for.



The dataset contains the following features:

Score in cybersecurity test: A numeric score indicating the user's performance on cybersecurity test.
Age: User's age.
Number of government services registered: Number of government services the user is registered with.
Educational level: The user's level of education (e.g., ثانوي, دراسات عليا, تقني).
Nature of work: The user's job type (e.g., حر, غير تقني).
Number of incorrect password entries: Count of times the user entered an incorrect password.
Number of password recovery attempts: Number of attempts to recover passwords.
Rating: A categorical label (e.g., جيد جدًا, ضعيف) representing the user's awareness level of cybersecurity risks.
